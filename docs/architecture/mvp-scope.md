# Prism MVP Scope

## In Scope

- Single-user experience.
- Multi-topic exploration.
- Curated lens catalog.
- Lens summary output.
- Key concept extraction.
- Explicit concept-to-concept connections.
- Retrieval-enabled generation flow.
- Regeneration flow with previous snapshot fallback.

## Out of Scope

- Team collaboration and permissions.
- Custom user-authored lens builder.
- Strict citation-per-claim enforcement.
- Publishing workflow and content governance.
- Advanced analytics dashboards.

## Core User Journey

1. User enters a topic.
2. User selects a lens.
3. System generates refracted summary, concepts, and connections.
4. User can regenerate without losing current stable output.
